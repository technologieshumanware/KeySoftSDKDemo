# Create a shortcut

The `commands.xml` file also allows you to create custom shortcuts for your
applications, either using the built-in Perkins keyboard or an externally
connected QWERTY keyboard.

It is not possible to create a shortcut with the same keybind as a global system shortcut keybind (list below)

For more information, refer to the `<key>` subsection in the `commands.xml` section.

See [SelfBraillingContextMenuActivity](../../app/src/main/java/com/humanware/keysoftsdkdemoapp/ui/SelfBraillingContextMenuActivity.kt) for an example of shortcuts within a context menu.
