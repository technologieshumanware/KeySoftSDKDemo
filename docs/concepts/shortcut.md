# Shortcut

## Overview

As with a QWERTY keyboard, it is possible to create and execute shortcuts on the Monarch using the Perkins keyboard. For example, using the dots Dots1359 (O + Space) opens the KeySoft Settings. It is also possible to execute shortcuts using a QWERTY keyboard.

To use QWERTY commands and display shortcuts in QWERTY format in the [Context Menu](./context-menu.md), a physical keyboard must be connected.

A standard practice is to put most shortcuts into the [Context Menu](./context-menu.md).
