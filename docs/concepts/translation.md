# Translation

## Overview

Most plain-text-to-Braille translation is handled automatically for common Android app scenarios (for example labels and menu items). However, if you have more specific translation needs (for example translating Braille back into several languages and showing those results), you may need to invoke the translator manually.

The SDK can translate plain text into Braille Unicode strings, and the other way around.

See the [translation example](../examples/translation.md) for a quick walkthrough.
